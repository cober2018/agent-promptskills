# 微信公众号运营

## 概述

公众号是"私域流量"核心阵地。**与短平快的公域平台不同，受众更愿意投入时间进行"深度阅读"。** 干货的密度和情绪的共鸣同等重要。

## 何时使用

- 公众号长图文深度内容策划
- 标题党适度法则（悬念 / 痛点 / 反差型）
- 排版呼吸感与阅读体验优化
- 私域沉淀与裂变诱饵设计
- 社交货币与金句设计
- 互动引导与评论区运营

**不要用于：** 短视频运营（用 `douyin-tiktok-operation`）、小红书图文笔记（用 `xhs-operation`）、B 站中长视频（用 `bilibili-operation`）、跨平台热点捕捉（用 `news-gathering`）。

## 标题党适度法则

公众号打开率（Open Rate）是生命线。**坚决抵制为了点击率而虚假夸大事实的"毒标题"，这会严重透支粉丝信任。**

| 标题类型 | 示例 |
|---|---|
| **悬念型** | 「那个辞职去摆摊的年轻人，现在怎么样了？」 |
| **痛点 / 干货型** | 「看了 100 份爆款文案，我总结出这 3 条万能公式」 |
| **反差型** | 「月薪 5000 和月薪 5 万的运营，到底差在哪里？」 |
| **数字型** | 「30 天涨粉 10 万，我只做了这 4 件事」 |
| **故事型** | 「他在地铁里被拒绝 100 次后，做出了这个决定」 |

| 禁忌 | 原因 |
|---|---|
| ❌ 标题与内容严重不符 | 透支信任，掉粉 |
| ❌ 震惊体、恐吓体 | 拉低品牌调性 |
| ❌ 标题过长（> 30 字） | 在手机端会被截断 |

## 深度内容与阅读体验

### 黄金开头

| 原则 | 说明 |
|---|---|
| 前 3 行点题 | 必须点明主题 |
| 故事 / 痛点引入 | 用一个小故事或痛点引入，让读者愿意继续往下划 |
| 价值预告 | 让读者知道"看完能获得什么" |

### 排版呼吸感

| 规则 | 说明 |
|---|---|
| 段落短 | 每段文字不要超过 3-4 行手机屏幕宽度 |
| 留白 | 大量使用留白、引语块（Blockquote）和分隔符 |
| 加粗 | 核心观点必须加粗，方便读者"扫读" |
| 配图 | 每 3-4 段插入相关配图，避免视觉疲劳 |
| 小标题 | 用清晰的 H2 / H3 小标题分章节 |

### 干货密度

对于专业领域（技术、金融、商业），必须提供：

| 要素 | 说明 |
|---|---|
| 深度分析 | 不仅给结论，给推导过程 |
| 图表 | 复杂数据用图表可视化 |
| 可落地的资料包 | 让读者"拿走就能用" |
| 真实案例 | 避免空谈理论 |

## 社交货币与分享裂变

### 为什么转发？

用户转发你的文章，是因为这篇文章能表达他们的品味、观点，或者能帮助别人。**内容必须为读者提供"社交货币"。**

| 社交货币类型 | 设计策略 |
|---|---|
| **身份认同** | "我们这群人就是……" |
| **观点表达** | 替读者说出他们想说但说不出的话 |
| **实用价值** | "转给需要的人" |
| **金句截图** | 视觉冲击力强，可独立传播 |

### 金句设计

| 位置 | 策略 |
|---|---|
| 文章高潮处 | 提炼一两句可截屏的金句 |
| 文章结尾 | 用一句总结性金句收束 |
| 小标题区 | 关键转折处用金句点睛 |

## 私域转化与互动引导

### 诱饵设计（Lead Magnet）

| 诱饵类型 | 示例 |
|---|---|
| **资料包** | 文末提供"回复【运营地图】获取高清原图" |
| **课程试听** | "扫码领取 199 元试听课" |
| **社群名额** | "前 100 名可加入私域交流群" |
| **工具模板** | "回复【PPT 模板】领取 50 套精选模板" |

### 互动引导

| 形式 | 说明 |
|---|---|
| 评论区引导 | "你在运营中踩过哪些坑？评论区聊聊" |
| 投票互动 | "你更支持 A 方案还是 B 方案？" |
| 转发激励 | "觉得有用就转给身边的朋友吧" |
| 关注引导 | 关注后第一时间接收更新 |

## 推送策略

| 时段 | 适用 | 说明 |
|---|---|---|
| 早 7:30-8:30 | 资讯类 | 通勤时段阅读 |
| 午 12:00-13:00 | 干货类 | 午休时段阅读 |
| 晚 20:00-21:30 | 深度长文 | 晚间黄金时段 |

**推送频率：** 1-2 篇 / 天为宜，质量优于数量。

## 常见错误

| 错误做法 | 正确做法 |
|---|---|
| 标题党与内容严重不符 | 标题适度吸引，内容必须兑现承诺 |
| 大段密集文字，无留白 | 段落 3-4 行，大量留白 |
| 无小标题、无加粗 | 核心观点加粗，清晰分章节 |
| 全文无金句、无可截屏点 | 高潮处提炼金句 |
| 无干货、无资料包 | 提供深度分析 + 图表 + 落地资料 |
| 无私域转化路径 | 文末设计 Lead Magnet |
| 7×24 随意推送 | 固定时段、固定频率推送 |
| 与读者零互动 | 评论区积极回复、引导讨论 |
| 纯文字长文无配图 | 每 3-4 段插一张相关图 |
| 文末无 CTA | 必须有明确的关注 / 转发 / 留言 CTA |
