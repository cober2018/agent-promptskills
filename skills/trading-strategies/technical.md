# A股技术策略知识包

用于 `china-market-analyst`。分析时先判断市场环境，再匹配策略，不要把单一技术信号直接等同于交易结论。

## 策略清单

| 策略名称 | 使用场景 | 关键判断 | 主要风险 |
|---|---|---|---|
| 均线策略 | 趋势确认、回踩确认 | MA5/10/20/60 多头排列、金叉、回踩不破 | 震荡市反复假突破 |
| 缠论策略 | 中枢、背驰、买卖点识别 | 中枢扩张、离开段力度、背驰、一二三类买卖点 | 主观划分过度 |
| 波浪策略 | 趋势阶段定位 | 推动浪、调整浪、延长浪、衰竭浪 | 数浪不唯一 |
| 趋势策略 | 主升、破位、趋势反转 | 高低点抬升、趋势线、平台突破、均线斜率 | 追高与假突破 |
| 成交量突破 | 平台突破或压力位突破 | 放量突破、换手放大、收盘站稳关键位 | 爆量冲高回落 |
| 缩量回踩 | 强势趋势中的低吸 | 回踩均线或平台，缩量止跌，再放量转强 | 趋势已坏仍低吸 |
| 底部放量 | 底部启动观察 | 长期缩量后放量、止跌结构、资金回流 | 下跌中继 |
| 箱体震荡 | 震荡区间交易 | 箱体上下沿、量能配合、假突破识别 | 趋势突破后逆势交易 |
| 龙头识别 | 热点主线中的强势股 | 涨幅、封板强度、带动性、辨识度、资金承接 | 高位一致后补跌 |
| 一阳穿三线/一阳三阴 | 趋势修复或反包 | 阳线实体、成交量、是否收复关键均线/阴线 | 情绪反抽不可持续 |
| 多指标融合 V1.03 | 多因子择时和风控 | 周线预筛、行业过滤、日线多因子、Regime/Fast Bear、ATR/拖尾止损 | 因子共振失效、过拟合 |

## 输出要求

- 明确列出命中的策略、未命中的关键条件、信号强弱。
- 技术结论必须和量能、位置、趋势阶段一起判断。
- A股必须说明涨跌停、换手、板块联动、资金承接对策略有效性的影响。
- 不直接给最终买卖结论，只给技术面支持、反对和等待条件。
