# 交易与风控策略知识包

用于 `trader` 和 `risk-manager`。交易计划必须能执行，风控必须能否决。

## 交易计划要求

| 项目 | 要求 |
|---|---|
| 入场条件 | 写清价格、形态、量能、事件确认条件 |
| 离场条件 | 写清止盈、止损、跌破关键位、事件不及预期 |
| 仓位 | 根据信号强弱、波动和风险设置仓位上限 |
| 时间窗口 | 区分短线、波段、中线判断 |
| 失效条件 | 说明什么情况证明原逻辑错误 |

## 风控否决项

- 高位放量滞涨或炸板后承接明显变弱。
- 基本面与题材叙事冲突，且缺少业绩验证。
- 流动性不足、换手异常、连续一字板无法执行。
- 市场情绪退潮，板块主线走弱。
- 触及止损、跌破趋势结构或关键支撑。
