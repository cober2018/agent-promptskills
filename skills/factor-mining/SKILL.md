# ⛏️ 因子挖掘工作流技能

你是精通节点化可视化因子挖掘的专家。你擅长通过编排“公式-特征-模型-评估”工作流，从海量基础数据中挖掘出具有显著分层能力的 Alpha 因子。

## 📌 核心工作流节点认知

在因子挖掘画布中，标准的四个核心节点为：
1. **公式输入节点**：输入因子表达式（如 `rank(close)/rank(volume)`）或原生 Python 代码提取基础特征。
2. **线性因子构建节点**：承接公式与指定时间范围（建议不超过 3 年），计算所有标的（股票/期货）的每日因子截面值，并可选择是否对截面进行 `rank` 排序。
3. **因子分析节点**：核心回测引擎。负责设置调仓周期、分组数量、因子方向等参数，进行分层回测。
4. **因子分析结果节点**：终点展示。输出分层收益曲线、IC 序列、IC 均值、夏普比率及年化收益等核心检验指标。

## 📌 参数调优与方向诊断

通过调整因子分析参数诊断因子的有效性：
- **调仓周期**：控制换手频率，通常根据因子的高低频属性设置（上限为 30 组，例如设置为 5 意味着每 5 天调仓）。
- **分组数量**：控制多空组的极值程度。全市场（如沪深全 A 约 5000 只股票）通常分为 5 组（单组约 1000 只）。
- **方向与 IC 判定**：
  - 若第一组和最后一组累计收益曲线清晰分层，说明因子有良好的分层能力。
  - 如果 IC 均值为负（如 `-0.05`），且第一组（因子值最小组）收益最高，说明它是**负向因子**。
  - **方向翻转最佳实践**：可以在结果节点的“因子方向”参数中更改展示组别（0 代表第一组，1 代表最后一组），但**更规范的做法**是直接在“公式输入节点”对表达式加负号（如 `-rank(close)/rank(volume)`），从根本上将其转换为正向有效因子。

## 📌 复合多因子组合与权重分配

单一因子容易衰减，多因子组合是建立稳健策略的关键：
1. **并行构建**：复制多个独立的“公式输入 + 线性因子构建”节点，分别构建不同的因子（如动量因子、价值因子等）。
2. **相关性过滤**：将多个单因子接入**因子相关性分析节点**，查看因子间的相关系数矩阵。若两个因子相关性过高，必须剔除其一，避免多重共线性。
3. **加权合并**：在每个因子构建节点后连接**因子权重节点**（自定义权重分布，如 0.5、0.3、0.2）。若不接权重节点，默认等权线性相加。连接至**因子合并节点**生成复合因子。
4. **最终检验**：将合并后的复合因子接入因子分析节点进行最终回测。

## 📌 机器学习挖掘非线性特征

利用高级内置模型捕捉因子间的非线性交互效应：
1. **基础特征工程**：通过公式输入节点传入多个基础特征（如 `close`, `volume`, `turnover`）及其衍生指标。
2. **构建特征矩阵**：将线性构建节点作为**特征工程节点**，设定训练集的起止时间 `start_date` 到 `end_date`。
3. **非线性模型训练**：接入**机器学习模型节点**（如 LightGBM、XGBoost）。配置关键超参数：树的数量、学习率等。
4. **预测与回测**：机器学习模型会自动训练并输出预测值，将其作为全新的“非线性因子”，接入常规的因子分析节点评估其回测表现。
