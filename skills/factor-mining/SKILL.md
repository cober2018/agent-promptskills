# 因子挖掘工作流

## 概述

通过编排「公式-特征-模型-评估」工作流，从海量基础数据中挖掘具有显著分层能力的 Alpha 因子。**节点化、可视化、端到端。**

## 何时使用

- 通过画布节点编排因子挖掘流程
- 多因子组合与权重分配
- 因子方向诊断（正向 / 负向）
- 机器学习非线性特征提取（LightGBM / XGBoost）
- 分层回测评估

**不要用于：** 单因子数学公式设计（用 `factor-engineering`）、回测引擎防偏误（用 `backtest-validation`）、因子回测后的实盘评估（用 `backtest-validation`）。

## 核心工作流节点

在因子挖掘画布中，标准的四个核心节点：

| 节点 | 作用 |
|---|---|
| **公式输入节点** | 输入因子表达式（如 `rank(close)/rank(volume)`）或原生 Python 代码提取基础特征 |
| **线性因子构建节点** | 承接公式与指定时间范围（建议不超过 3 年），计算所有标的（股票 / 期货）的每日因子截面值，可选择是否对截面进行 `rank` 排序 |
| **因子分析节点** | 核心回测引擎。设置调仓周期、分组数量、因子方向等参数，进行分层回测 |
| **因子分析结果节点** | 终点展示。输出分层收益曲线、IC 序列、IC 均值、夏普比率及年化收益等核心检验指标 |

## 参数调优与方向诊断

通过调整因子分析参数诊断因子的有效性：

| 参数 | 说明 |
|---|---|
| **调仓周期** | 控制换手频率，通常根据因子的高低频属性设置（上限为 30 组，例如设置为 5 意味着每 5 天调仓） |
| **分组数量** | 控制多空组的极值程度。全市场（沪深全 A 约 5000 只股票）通常分为 5 组（单组约 1000 只） |

**方向与 IC 判定：**

| 现象 | 结论 | 处置 |
|---|---|---|
| 第一组和最后一组累计收益曲线清晰分层 | 因子有良好分层能力 | 继续评估 IC 序列 |
| IC 均值为负（如 -0.05），且第一组（因子值最小组）收益最高 | 负向因子 | 在结果节点「因子方向」参数中翻转展示组别 |
| 规范化做法 | — | **直接在「公式输入节点」对表达式加负号**（如 `-rank(close)/rank(volume)`），从根本上转换为正向有效因子 |

## 复合多因子组合与权重分配

单一因子容易衰减，多因子组合是建立稳健策略的关键：

**步骤：**

1. **并行构建：** 复制多个独立的「公式输入 + 线性因子构建」节点，分别构建不同的因子（如动量因子、价值因子等）。
2. **相关性过滤：** 将多个单因子接入「因子相关性分析节点」，查看因子间的相关系数矩阵。若两个因子相关性过高，必须剔除其一，避免多重共线性。
3. **加权合并：** 在每个因子构建节点后连接「因子权重节点」（自定义权重分布，如 0.5、0.3、0.2）。若不接权重节点，默认等权线性相加。连接至「因子合并节点」生成复合因子。
4. **最终检验：** 将合并后的复合因子接入因子分析节点进行最终回测。

**权重选择参考：**

| 场景 | 权重策略 |
|---|---|
| 因子质量相近、相关性低 | 等权（0.2 × 5） |
| 因子 IC 差异显著 | 按 IC IR 加权（高 IR 因子权重大） |
| 因子相关性高 | 先剔除高相关因子，再等权 |

## 机器学习挖掘非线性特征

利用高级内置模型捕捉因子间的非线性交互效应：

1. **基础特征工程：** 通过公式输入节点传入多个基础特征（如 `close`, `volume`, `turnover`）及其衍生指标。
2. **构建特征矩阵：** 将线性构建节点作为「特征工程节点」，设定训练集的起止时间 `start_date` 到 `end_date`。
3. **非线性模型训练：** 接入「机器学习模型节点」（如 LightGBM、XGBoost）。配置关键超参数：树的数量、学习率等。
4. **预测与回测：** 机器学习模型会自动训练并输出预测值，将其作为全新的「非线性因子」，接入常规的因子分析节点评估其回测表现。

## 常见错误

| 错误做法 | 正确做法 |
|---|---|
| 全市场只分 2 组（多空） | 分 5 组甚至 10 组，看单调性 |
| 调仓周期 1 天（过度交易） | 按因子高低频属性设置（5-30 天） |
| 多因子不查相关性直接合成 | 必须做相关性分析，剔除高相关因子 |
| 多个因子统一等权 | 按 IC IR 加权或优化权重 |
| 训练集和测试集没分开 | 必须 Out-of-Sample 验证防过拟合 |
| 拿 ML 模型输出当万能因子 | ML 因子仍需 IC 评估，警惕过拟合 |
| 在结果节点改方向展示组别 | 直接在公式输入节点对表达式加负号 |
