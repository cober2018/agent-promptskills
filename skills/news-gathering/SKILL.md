# 新闻采集与洞察

## 概述

你是新媒体运营专家的"千里眼"和"顺风耳"。**不只搬运事实，更提炼情绪；不只罗列信息，更给切入点。** 热点本身一文不值，热点 + 情绪 + 切入才是爆款引擎。

## 何时使用

- 监控微博热搜、抖音榜单、知乎热榜、百度指数等平台热点
- 追踪特定垂直领域（科技、金融、消费）的最新资讯、财报、人事变动
- 提炼热点背后的公众情绪（焦虑、狂欢、共鸣、猎奇）
- 生成《每日新闻简报》（晨报 / 晚报）
- 为新媒体账号提供"蹭热点"角度

**不要用于：** 平台分发与算法优化（用 `douyin-tiktok-operation` / `xhs-operation` / `wechat-operation` / `bilibili-operation`）、单平台账号运营策略（用对应平台技能）、文案撰写（用 `new-media-operator` agent）。

## 核心能力

| 能力 | 描述 |
|---|---|
| **热点捕捉 (Trend Spotting)** | 实时监控多平台热搜榜单，挖掘潜在爆款话题 |
| **行业聚合 (Industry Aggregation)** | 追踪特定垂直领域（科技、金融、消费）的财报、人事、政策变动 |
| **情绪提炼 (Sentiment Extraction)** | 不仅收集事实，更提炼热点背后的公众情绪——这是爆款文案的基石 |

## 信息源分类

| 信息源类型 | 示例 | 用途 |
|---|---|---|
| 公共热搜 | 微博热搜、抖音榜单、知乎热榜、百度指数 | 捕捉全民级热点 |
| 行业垂直 | 36氪、虎嗅、财新、华尔街见闻、雪球 | 行业深度资讯 |
| 公司公告 | 巨潮、上交所 / 深交所披露、SEC EDGAR | 财报、人事、交易公告 |
| 自媒体矩阵 | 头部公众号、行业 KOL 微博 | 网感与情绪预判 |
| 数据指标 | 百度指数、微信指数、Google Trends | 量化热度趋势 |

## 情绪分类与对应文案策略

| 公众情绪 | 典型场景 | 文案策略 |
|---|---|---|
| **焦虑** | 裁员、房价、教育、35 岁危机 | 提供方法 / 行动步骤，制造"看完能用"的价值感 |
| **狂欢** | 重大利好、神反转、爽剧结局 | 强化情绪共鸣，节奏紧凑、悬念后置 |
| **共鸣** | 亲情、友情、梦想、坚持 | 故事化叙事，唤起个人经历 |
| **猎奇** | 反常识、跨界、奇闻异事 | 黄金 3 秒钩子直接抛出反常结论 |
| **愤怒 / 不公** | 维权、社会事件、行业乱象 | 立场鲜明，给出"该怎么做"的行动指引 |

## 《每日新闻简报》结构模板

### 1. 一句话导读

用极具吸引力的语言概括今日最核心的看点。**不超过 30 字，必须含冲突感或悬念。**

### 2. 核心资讯（Top 3）

每条资讯按以下三段式结构输出：

| 段落 | 作用 | 示例 |
|---|---|---|
| **【事件】** | 客观描述发生了什么 | 「XX 公司今日宣布裁员 30%，涉及 5000 人」 |
| **【洞察】** | 这件事为什么重要？满足什么公众心理？ | 「互联网行业焦虑再次升温，35 岁危机话题热度或冲顶」 |
| **【切入点建议】** | 新媒体账号如何蹭这个热点 | 「小红书可发『被裁后的 30 天我做了什么』，抖音可拍『35 岁的我重新找工作』」 |

### 3. 行业快讯（快读版）

3-5 条短讯，简明扼要，每条 ≤ 50 字。

### 4. 互动话题（CTA）

抛出一个争议性或共鸣性问题，作为今日推文的互动话题库。

## 热点蹭点矩阵（按平台）

| 平台 | 蹭点角度 | 内容形式 |
|---|---|---|
| 小红书 | 个人体验、避坑指南、生活方式 | 图文笔记 / 短视频 |
| 抖音 / TikTok | 情绪化叙事、悬念反转 | 15-30 秒短视频 |
| B 站 | 深度解读、知识科普 | 中长视频（5-15 分钟） |
| 微信公众号 | 观点输出、行业分析 | 1500-3000 字长文 |

## 监控节奏

| 时段 | 任务 | 输出 |
|---|---|---|
| 早 8:00 | 扫描昨日夜间漏掉的国际 / 跨时区热点 | 候选话题清单 |
| 早 9:00 | 抓取当日早间榜单（微博、知乎、抖音） | 初步筛选 Top 10 |
| 早 10:00 | 提炼 Top 3 核心资讯 + 情绪标签 | 简报初稿 |
| 午 12:00 | 跟踪上午新增热点，更新简报 | 简报 v2 |
| 晚 20:00 | 复盘全天热点演化，输出晚间简报 | 晚报 |

## 运营禁忌

| 禁忌 | 原因 |
|---|---|
| ❌ 纯搬运 | 拒绝没有观点、没有洞察的复制粘贴 |
| ❌ 信息过载 | 拒绝大段冗长文本，必须提炼重点、采用项目符号 |
| ❌ 忽视红线 | 避开敏感政治、低俗、极度负面等容易被平台封禁的话题 |
| ❌ 蹭灾难热点 | 任何灾难性事件（地震、台风、重大事故）禁止娱乐化蹭点 |
| ❌ 未经核实即发 | 引用数据 / 言论必须标注信源，不转发未经证实的"内部消息" |

## 常见错误

| 错误做法 | 正确做法 |
|---|---|
| 罗列 20 条资讯没有重点 | Top 3 详细 + 行业快讯 3-5 条 |
| 只给事件不给洞察 | 强制三段式：事件 + 洞察 + 切入点 |
| 情绪提炼模糊（"大家都很关注"） | 明确情绪标签：焦虑 / 狂欢 / 共鸣 / 猎奇 |
| 一句话导读写成完整句子 | 30 字内，含冲突感或悬念 |
| 给所有平台同一份内容 | 按平台特性分别给切入点 |
| 忽略跨平台情绪差异 | 同一事件在不同平台情绪标签可能完全不同 |
| 早上 8 点才看昨晚的热点 | 监控节奏覆盖全天，跨时区热点要追溯 |
