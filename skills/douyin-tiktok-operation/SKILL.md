# 抖音 / TikTok 运营法则

## 概述

抖音 / TikTok 是极度内卷的短视频战场。用户的耐心只有 3 秒——**没有在前 3 秒抓住他们，视频就会被无情划走。**

## 何时使用

- 抖音 / TikTok 短视频脚本（15-30 秒最佳）
- 黄金 3 秒钩子设计
- 完播率与互动率优化
- 热门 BGM 选择与卡点
- 字幕与封面策略
- 标题与 Tag 优化

**不要用于：** 小红书图文（用 `xhs-operation`）、B 站中长视频（用 `bilibili-operation`）、公众号长文（用 `wechat-operation`）。

## 黄金三秒法则（The 3-Second Hook）

### 视觉钩子

开场必须有强烈的视觉冲击、夸张动作、不寻常场景，或直接展示最终惊艳成果。

### 听觉 / 文案钩子

| 类型 | 示例 |
|---|---|
| 发出疑问 | 「你绝对不敢相信……」 |
| 挑战认知 | 「一直以来你的做法可能都是错的！」 |
| 承诺价值 | 「花 15 秒钟，帮你省下 1000 块。」 |
| 痛点共鸣 | 「我猜你也遇到过这种情况……」 |

**禁忌：** 严禁前奏过长、严禁冗长的自我介绍。

## 算法漏斗与数据优化

平台的推荐流量池基于用户反馈数据。**优化优先级：完播率 > 转发 > 评论 > 点赞。**

| 指标 | 优化手段 |
|---|---|
| **提升完播率** | 控制时长（新手 15-30 秒）；去掉所有气口、停顿和废话；悬念后置（最大悬念放结尾） |
| **提升互动率（评论 / 转发）** | 预留槽点（故意留小瑕疵或争议点）；利益诱导（「@你的闺蜜来看」「想要清单的扣 1」） |

## 音乐与视听语言

**BGM 策略：** 坚决跟风！使用当前平台最热门、最有卡点感、最有情绪的 BGM 作为背景音。

**字幕要求：**

- 必须带字幕（70% 观看场景是静音或嘈杂环境）。
- 字幕要大，居中偏下。
- 避开右侧头像、底部文案安全区。
- 关键词用高对比色（如黑底白字 + 描边）。

## 标题与封面

| 元素 | 要求 |
|---|---|
| 文案 | 不如视频本身重要，但标题要包含搜索关键词 |
| Tag | 添加 3-5 个热门 HashTag（如 `#涨知识` `#搞笑日常`） |
| 封面 | 选视频中最具爆发力的一帧；信息量大、有视觉中心 |

## 常见错误

| 错误做法 | 正确做法 |
|---|---|
| 5-10 秒冗长片头 | 1-2 秒直接进入主题或最精彩画面 |
| 节奏拖沓、大量停顿 | 节奏紧凑，去掉气口、废话、重复 |
| 静音无字幕 | 必须加字幕，覆盖 70% 静音场景 |
| 文末无悬念 | 悬念后置在结尾，引导完播 |
| 用过气 BGM | 紧跟当前平台热门 BGM |
| Tag 瞎写 | 用 3-5 个相关热门 HashTag |
| 封面色调混乱 | 高对比度、视觉中心明确 |
