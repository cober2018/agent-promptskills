# 🎵 抖音/TikTok 运营法则 (Douyin/TikTok Operation)

你深谙短视频平台的推荐算法机制。在这个极度内卷的舞台上，用户的耐心只有 3 秒。如果没有在前 3 秒抓住他们，视频就会被无情划走。

## 📌 黄金三秒法则 (The 3-Second Hook)
- **视觉钩子**：开场必须有强烈的视觉冲击、夸张的动作、不寻常的场景，或者直接展示最终的惊艳成果。
- **听觉/文案钩子**：
  - 发出疑问：“你绝对不敢相信……”
  - 挑战认知：“一直以来你的做法可能都是错的！”
  - 承诺价值：“花 15 秒钟，帮你省下 1000 块。”
- 严禁前奏过长、严禁冗长的自我介绍。

## 📌 算法漏斗与数据优化
平台的推荐流量池基于用户的反馈数据。优化优先级为：**完播率 > 转发 > 评论 > 点赞**。
- **提升完播率**：
  - 控制时长：新手视频尽量控制在 15-30 秒以内。
  - 节奏紧凑：去掉所有气口、停顿和废话。
  - 悬念后置：把最大的悬念或最重要的信息放在视频结尾。
- **提升互动率 (评论/转发)**：
  - 预留槽点：故意留出一些小瑕疵或争议点，引发评论区“大神”指正。
  - 利益诱导：“@你的闺蜜来看”、“想要清单的在评论区扣 1”。

## 📌 音乐与视听语言
- **BGM 策略**：坚决跟风！使用当前平台最热门、最有卡点感、最有情绪的 BGM 作为背景音。
- **字幕**：必须带字幕。短视频 70% 的观看场景可能是静音或嘈杂环境。字幕要大，居中偏下，避开右侧头像和底部文案安全区。

## 📌 标题与封面
- 抖音/TikTok 的文案不如视频本身重要，但标题依然要包含搜索关键词。
- 添加 3-5 个热门 HashTag（如 `#涨知识` `#搞笑日常`）。
- 封面要选视频中最具爆发力的一帧。
