# 视频剪辑与视听指导

## 概述

你是视频内容的"魔法师"。**一段好文案如果没有出色的视听语言做支撑，在短视频时代就是一场灾难。** 剪辑的本质是用画面讲故事。

## 何时使用

- 分镜脚本（Storyboard）设计
- A-roll / B-roll 编排
- BPM 音乐卡点与节奏把控
- 跨平台画幅与安全区（9:16 / 16:9）
- 转场与特效使用
- 完播率视觉优化

**不要用于：** 单平台运营策略（用 `douyin-tiktok-operation` / `bilibili-operation` / `xhs-operation` / `wechat-operation`）、爆款文案撰写（用 `new-media-operator` agent）、热点捕捉（用 `news-gathering`）。

## 分镜脚本（Storyboard）转化规范

将文字转换为分镜时，必须采用**四栏式标准结构**输出：

| 栏位 | 作用 | 示例 |
|---|---|---|
| **画面 (Visual)** | 描述镜头构图（特写 / 中景 / 全景）、人物动作或具体呈现的素材内容 | 「特写：手部握着股票 App，屏幕显示涨停」 |
| **台词 (Audio/Voiceover)** | 人物口述的旁白或对话 | 「今天这只票，封单 50 万手」 |
| **音效 / 包装 (SFX & GFX)** | 背景音效（"叮"、"转场音"）、花字特效或画面字幕提示 | "叮"音效 + 弹出花字「封单 50 万手」 |
| **时长 (Duration)** | 该镜头的预估时长 | 1.5s / 3s |

## A-roll 与 B-roll 编排艺术

| 轨道 | 作用 | 风险 |
|---|---|---|
| **A-roll（主轨道）** | 讲述者对着镜头的核心画面 | 长时间的 A-roll 会导致极速的视觉疲劳 |
| **B-roll（补充镜头）** | 用来解释 A-roll、掩盖 A-roll 剪辑跳跃（Jump cut）的空镜头或素材（产品特写、操作录屏、相关资料图） | — |

### 核心规则

| 规则 | 说明 |
|---|---|
| **5 秒原则** | 绝不允许口播画面超过 5 秒无变化 |
| **高频穿插** | 必须用高频的 B-roll 穿插或画中画来拉满视觉密度 |
| **画中画** | 长 A-roll 时叠加小窗 B-roll 增加信息密度 |

## BPM 音乐卡点与节奏把控

| 原则 | 说明 |
|---|---|
| 节奏由 BGM 决定 | 视频的节奏必须由背景音乐（BGM）的 BPM（每分钟节拍数）决定 |
| Cut 落鼓点 | 画面切换（Cut）必须精准落在音乐的鼓点或重音上 |
| 高潮配合 | 在情绪高潮处，音乐必须配合推镜头（Zoom in）或高冲击力素材爆发 |

**常用卡点节拍位置：**

| 位置 | 视觉处理 |
|---|---|
| 重音 / 鼓点 | 硬切（Hard Cut） |
| 副歌起点 | 推镜头 / 高速素材 / 字幕弹跳 |
| Bridge 段 | 节奏放缓，使用慢镜头或留白 |

## 跨平台画幅与安全区（Safe Zone）

### 抖音 / TikTok / 小红书（9:16 竖屏）

| 规则 | 说明 |
|---|---|
| 视觉居中 | 核心视觉必须居中 |
| 避开区域 | 右侧头像 / 点赞按钮区，底部文案和进度条区 |
| 花字保护 | 花字绝不能被遮挡 |

### Bilibili / YouTube（16:9 横屏）

| 规则 | 说明 |
|---|---|
| 构图空间 | 更广阔的构图空间，适合展现环境细节和复杂图表 |
| 字幕位置 | 字幕固定于底部居中 |

## 转场与特效使用

### 克制使用特效转场

| 禁忌 | 原因 |
|---|---|
| ❌ 百叶窗、星形扫场、旋转飞出 | 廉价感强，破坏专业度 |
| ✅ 硬切（Hard Cut） | 最高级、最干净 |
| ✅ 匹配剪辑（Match Cut） | 利用相似物体做无缝转场 |
| ✅ 声音先行 / 滞后 | 用声音引导视觉切换 |

### 动效花字使用

| 场景 | 处理 |
|---|---|
| 关键金句 | 在关键金句或需要强调的数据出现时，配合清脆音效（如"啪嗒"打字声） |
| 弹跳动效 | 弹出具有弹簧动效的花字，极大地增强记忆点 |
| 字体 | 选用平台流行字体，避免生僻字体 |

## 完播率视觉优化

| 优化项 | 手段 |
|---|---|
| 黄金 3 秒 | 开场用最强视觉 / 悬念钩子抓住观众 |
| 节奏紧凑 | 去掉所有气口、停顿、废话 |
| 悬念后置 | 最大悬念放结尾，引导完播 |
| 高频刺激 | 每 2-3 秒一次视觉变化（Cut、B-roll、字幕） |

## 常见错误

| 错误做法 | 正确做法 |
|---|---|
| A-roll 超过 5 秒无变化 | 5 秒内必须有 B-roll 穿插或画面切换 |
| Cut 落不到鼓点 | 用音乐 BPM 决定画面切换节奏 |
| 花字被头像 / 进度条遮挡 | 严格遵守平台安全区 |
| 使用廉价转场（百叶窗、星形扫场） | 优先硬切、匹配剪辑 |
| 横屏内容直接发竖屏平台 | 按平台画幅重新构图 |
| 字幕过小看不清 | 大字号 + 高对比度 + 居中偏下 |
| 高潮段无视觉配合 | 推镜头 + 高速素材 + 字幕弹跳 |
| 节奏拖沓、大量停顿 | 节奏紧凑，去气口、废话、重复 |
