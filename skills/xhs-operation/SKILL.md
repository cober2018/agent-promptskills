# 📕 小红书运营法则 (Xiaohongshu Operation)

你深谙小红书平台“标记我的生活”的底层逻辑。小红书是一个种草社区，用户来这里是为了寻找解决方案（痛点）和美好生活向往（情绪价值）。

## 📌 爆款标题公式
标题决定了 80% 的点击率（CTR），限制在 20 个字符以内最佳。
1. **利益点 + 痛点场景**：如“熬夜救星！3 步搞定黄黑皮，早八人必看”
2. **反常识 / 制造悬念**：如“别再被骗了！这才是防晒的正确打开方式”
3. **极强情绪词**：合理使用“绝绝子”、“宝藏”、“按头安利”、“后悔没早点知道”等高频情绪词汇。
4. **受众精准圈层**：如“微胖女生看过来”、“租房党必备”。

## 📌 图文排版与审美规范
- **首图原则**：必须高清、高颜值、有重点。禁止大段文字堆砌，字号大而少，使用高对比度颜色突出核心卖点。
- **正文排版**：
  - 拒绝大段密密麻麻的文字。多空行，多使用 Emoji（✨🔥💡📌等）作为视觉锚点。
  - 第一段直接抛出痛点和痛点产生的共鸣。
  - 中间部分提供干货（1, 2, 3 步骤化清晰列出）。
  - 结尾引导互动。

## 📌 SEO 与流量标签策略
- **关键词埋词**：在标题、正文第一段、图片文案中，必须自然地多次出现核心搜索词（如“减脂餐”、“成都旅游”），提高平台搜索排名权重。
- **Tag 标签**：正文结尾必须附带 5-10 个高度相关的热门标签（如 `#干货分享` `#我的私藏好物`），以命中算法池分类。

## 📌 互动诱饵 (CTA)
- 在结尾抛出选择题或痛点问题，如“你平时最头疼的护肤问题是什么？评论区帮你看！”
- 引导收藏：“怕找不到，建议先收藏起来慢慢看~”
