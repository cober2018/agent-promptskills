# 小红书运营

## 概述

小红书是"标记我的生活"的种草社区。**用户来寻找解决方案（痛点）和美好生活向往（情绪价值）。** 标题决定 80% 点击率，首图决定收藏率。

## 何时使用

- 小红书图文笔记内容策划
- 爆款标题公式（20 字以内）
- 图文排版与首图审美
- SEO 关键词埋词
- Tag 标签策略（5-10 个热门标签）
- 互动诱饵（CTA）设计

**不要用于：** 短视频运营（用 `douyin-tiktok-operation`）、公众号长文（用 `wechat-operation`）、B 站中长视频（用 `bilibili-operation`）、跨平台热点捕捉（用 `news-gathering`）。

## 爆款标题公式

**标题决定 80% 的点击率（CTR），限制在 20 个字符以内最佳。**

| 公式 | 示例 |
|---|---|
| **利益点 + 痛点场景** | 「熬夜救星！3 步搞定黄黑皮，早八人必看」 |
| **反常识 / 制造悬念** | 「别再被骗了！这才是防晒的正确打开方式」 |
| **极强情绪词** | 「绝绝子」「宝藏」「按头安利」「后悔没早点知道」 |
| **受众精准圈层** | 「微胖女生看过来」「租房党必备」 |
| **数字 + 解决方案** | 「5 个 PPT 神器，做幻灯片快 10 倍」 |
| **场景代入** | 「约会前 30 分钟必做的 3 件事」 |

## 痛点 + 情绪价值双引擎

| 引擎 | 作用 | 挖掘方法 |
|---|---|---|
| **痛点** | 给用户"我能解决你的问题"的价值感 | 评论区高频问题、搜索下拉词、竞品爆款笔记 |
| **情绪价值** | 唤起共鸣（焦虑 / 治愈 / 向往 / 爽快） | 个人经历代入、情绪渲染、夸张表达 |

**双引擎组合公式：** 痛点场景引入 + 情绪共鸣强化 + 解决方案干货 + 情绪升华结尾。

## 图文排版与审美规范

### 首图原则

| 原则 | 说明 |
|---|---|
| 高清高颜值 | 必须高清、高颜值、有重点 |
| 拒绝文字堆砌 | 禁止大段文字堆砌 |
| 字号大而少 | 大字号 + 少量关键词 |
| 高对比度 | 高对比度颜色突出核心卖点 |
| 视觉中心 | 一个主视觉 + 2-3 个辅助元素 |
| 留白 | 不要塞满画面，留出视觉呼吸空间 |

### 正文排版

| 规则 | 说明 |
|---|---|
| 多空行 | 拒绝大段密密麻麻的文字 |
| Emoji 视觉锚点 | 多用 Emoji（✨🔥💡📌✅❌）作为视觉锚点 |
| 痛点开头 | 第一段直接抛出痛点和痛点产生的共鸣 |
| 步骤化干货 | 中间部分提供干货（1、2、3 步骤化清晰列出） |
| 互动结尾 | 结尾引导互动 |

## SEO 关键词埋词

**目标：** 提高平台搜索排名权重，命中搜索流量。

| 位置 | 埋词策略 |
|---|---|
| **标题** | 必须包含核心搜索词 |
| **正文第一段** | 自然出现核心搜索词（搜索引擎最看重） |
| **图片文案** | 在 2-3 张图中嵌入搜索词 |
| **正文中间** | 重复 1-2 次核心搜索词（不要堆砌） |
| **结尾 Tag** | 包含 1-2 个核心搜索词作为 Tag |

**埋词密度：** 核心词出现 3-5 次为佳，过度堆砌会被降权。

## Tag 标签策略

**正文结尾必须附带 5-10 个高度相关的热门标签**，命中算法池分类。

| 标签类型 | 示例 |
|---|---|
| **核心搜索词** | `#减脂餐` `#成都旅游` |
| **大流量泛标签** | `#干货分享` `#我的私藏好物` `#日常分享` |
| **平台活动标签** | 平台正在推的活动（每周更新） |
| **垂类细分标签** | `#微胖穿搭` `#租房改造` |
| **情绪共鸣标签** | `#治愈自己` `#自律生活` |

**标签组合策略：** 2-3 个大流量标签 + 3-5 个垂类细分标签 + 1-2 个活动标签。

## 互动诱饵（CTA）

| 类型 | 示例 |
|---|---|
| **选择题** | 「你平时最头疼的护肤问题是什么？评论区帮你看！」 |
| **痛点问题** | 「姐妹们有没有遇到过……的情况？」 |
| **收藏引导** | 「怕找不到，建议先收藏起来慢慢看~」 |
| **关注引导** | 「关注我，下期分享更多……技巧」 |
| **求互动** | 「你觉得有用吗？评论区扣 1」 |

## 笔记发布节奏

| 时段 | 适用内容 |
|---|---|
| 早 7:00-9:00 | 通勤 / 早餐 / 资讯类 |
| 午 12:00-14:00 | 美食 / 午休 / 穿搭类 |
| 晚 19:00-22:00 | 黄金时段：护肤、彩妆、剧情、深度干货 |
| 周末上午 | 生活方式、旅行、家居 |

**频率建议：** 日更 1-2 篇，质量优于数量。

## 数据指标关注

| 指标 | 优秀基线 | 说明 |
|---|---|---|
| 点击率（CTR） | > 8% | 标题 + 封面吸引力 |
| 互动率 | > 5% | 点赞 + 收藏 + 评论 / 阅读 |
| 收藏率 | > 3% | 内容实用价值 |
| 涨粉率 | > 0.5% | 关注转化 |

## 常见错误

| 错误做法 | 正确做法 |
|---|---|
| 标题过长（> 20 字） | 控制在 20 字以内，重点前置 |
| 首图文字堆砌 | 字号大而少，视觉中心明确 |
| 正文大段密集文字 | 多空行 + Emoji 视觉锚点 |
| 不埋关键词 | 标题 / 首段 / Tag 必须有核心搜索词 |
| Tag 数量过多（> 15）或过少（< 3） | 5-10 个最相关标签 |
| Tag 全部用大流量词 | 大流量 + 垂类细分 + 活动组合 |
| 无 CTA 引导互动 | 结尾必须有互动诱饵 |
| 全是干货无情绪共鸣 | 痛点 + 情绪 + 干货 + 情绪四段式 |
| 发布时间随意 | 固定黄金时段发布 |
| 频率过高或过低 | 1-2 篇 / 天，固定节奏 |
| 数据差就放弃 | 持续优化 2-3 周后再判断方向 |
