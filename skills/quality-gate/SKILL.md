🚦 质量门禁（Quality Gate & Deployment Readiness）
核心问题：系统真的准备好了吗？声明有证据支持吗？能上生产吗？


📌 集成测试方法论

  现实检查命令（每次评估必须执行）：
    1. 验证实际构建了什么（检查文件结构和内容）
    2. 交叉检查声称的功能（grep 关键特性关键词）
    3. 运行自动化截图捕获（多设备、多状态）
    4. 审查所有证据（截图 + 测试结果 JSON）

  QA 交叉验证：
    审查 QA Agent / 测试工程师的发现
    将自动化截图与之前的评估进行交叉引用
    用额外的自动化证据确认或质疑之前的评估
    验证之前报告的问题是否已修复


📌 端到端用户旅程测试

  测试方法：
    从用户视角走完核心业务流程
    每个步骤都记录截图证据
    记录步骤间的过渡是否流畅
    记录数据是否正确传递

  旅程报告模板：

    端到端用户旅程证据
    旅程：首页 → 导航 → 核心功能 → 结果确认

    步骤 1 — 入口页面：
      截图证据：[responsive-desktop.png] 显示的实际内容
      性能：页面加载时间 [X] ms
      可见问题：[基于截图的诚实描述]

    步骤 2 — 导航交互：
      截图证据：[nav-before.png] vs [nav-after.png]
      功能性：导航是否正确响应？跳转是否正确？
      可见问题：[基于对比截图的发现]

    步骤 3 — 核心功能：
      截图证据：[功能操作前后截图]
      数据正确性：输入是否正确处理？输出是否符合预期？
      可见问题：[基于证据的发现]

    旅程评估：PASS / FAIL，附具体证据引用


📌 跨设备验证

  必须验证的设备尺寸：
    桌面端：1920x1080（主流桌面分辨率）
    平板端：768x1024（iPad 竖屏）
    移动端：375x667（iPhone SE / 标准移动端）

  验证项目：
    布局是否在所有尺寸下正确显示
    交互元素是否可点击/可触摸
    文字是否可读（不被截断、不溢出）
    图片是否正确缩放
    滚动行为是否正常

  证据要求：
    每个设备尺寸至少一张完整页面截图
    布局异常处用标注指出问题


📌 性能验证

  验证项目：
    页面首次加载时间 < 3 秒（LCP）
    交互响应时间 < 100ms（FID）
    布局稳定性（CLS < 0.1）
    API 响应时间 < 500ms（核心接口）

  证据要求：
    Performance 面板截图或 Lighthouse 报告
    关键 API 的实际响应时间数据
    如有性能问题，标注具体瓶颈


📌 规格合规性检查

  检查方法：
    逐条对照原始需求/规格文档
    每条需求标注：已实现 / 部分实现 / 未实现
    部分实现和未实现的项目附上证据

  报告模板：
    规格说明与实现对比
    原始规格要求："[引用准确文本]"
    实际实现："[截图中实际显示的内容]"
    差距分析："[缺失或不同的内容]"
    合规状态：PASS / PARTIAL / FAIL


📌 质量认证评级

  评级标准（残酷诚实）：

    D — 基本功能不可用
      核心流程断裂，无法完成主要任务
      多个 P0 级 Bug

    C — 功能可用但问题较多
      核心流程可完成但有明显问题
      多个 P1 级 Bug
      这是首次实现的正常水平

    B — 良好，有改进空间
      核心流程流畅
      仅有 P2/P3 级问题
      性能达标

    A — 优秀，接近生产就绪
      所有功能完整且稳定
      性能优秀
      跨设备表现一致
      需要压倒性证据才能给出此评级

  原则：
    C+/B- 是首次实现的正常水平
    首次提交通常需要 2-3 个修订周期
    "生产就绪"需要已证明的卓越表现
    诚实的反馈驱动更好的结果


📌 部署就绪性评估

  评估维度：

    功能完整性：
      所有规格要求是否已实现？
      核心用户旅程是否完整？
      边界条件和异常处理是否覆盖？

    质量稳定性：
      P0 Bug 数量 = 0（必须条件）
      P1 Bug 数量 = 0（强烈建议）
      P2 Bug 数量 ≤ 3（可接受但需记录）
      回归测试全部通过

    性能达标：
      关键页面加载 < 3s
      核心 API 响应 < 500ms
      无内存泄漏或资源泄漏

    跨环境一致性：
      开发/Staging/预发布环境表现一致
      跨设备跨浏览器基本一致

  评估结论：
    READY — 可以部署（极少，需要压倒性证据）
    NEEDS WORK — 需要修复后重新评估（默认状态）
    FAILED — 存在严重问题，不得部署
