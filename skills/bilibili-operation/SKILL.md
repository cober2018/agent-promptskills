# B 站运营法则

## 概述

B 站是 Z 世代（年轻人）文化社区，用户极度看重「真实感」「干货度」和「社区氛围」。他们不喜欢生硬的广告，但会为优质内容「一键三连」（点赞 + 投币 + 收藏）。**真诚是必杀技，造梗是催化剂。**

## 何时使用

- B 站中长视频脚本（3-15 分钟）
- 视频结构化（序章 / 正片 / 片尾）
- 弹幕互动点预埋（名场面、梗点）
- 封面与标题设计（B 站重度依赖封面）
- UP 主人设定位与口头禅设计

**不要用于：** 抖音短视频（用 `douyin-tiktok-operation`）、小红书图文（用 `xhs-operation`）、微信公众号长文（用 `wechat-operation`）。

## 视频结构化法则（The Bilibili Formula）

| 阶段 | 时长 | 要点 |
|---|---|---|
| **序章** | 前 30 秒 | 交代背景，抛出悬念或直接展示最震撼结论（切忌冗长无聊片头） |
| **正片** | 中段 3-12 分钟 | 保持高信息密度；知识区需严谨数据论证，生活区需密集情绪起伏；每 1-2 分钟抛出一个笑点或反转 |
| **片尾** | 30-60 秒 | 总结升华，下期预告，真诚求关注、点赞、投币、收藏 |

## 弹幕造梗与互动预埋

B 站的灵魂是弹幕。内容策划时必须**故意留出弹幕互动空间**：

| 手法 | 说明 |
|---|---|
| **疑问预留** | 主播故意装傻或抛问题，引导弹幕满屏刷答案 |
| **名场面制造** | 夸张表情、经典 BGM 变奏或网络热梗，诱发「前方高能」「草率了」「学到了」刷屏 |
| **金句包装** | 关键观点做成大字花字 + 慢放，便于截屏传播 |

**为什么弹幕重要？** 弹幕越多，视频在算法池中的活跃度权重越高，平台会推给更多观众。

## 封面与标题（Title & Thumbnail）

**封面审美：**
- 信息量大、有视觉中心（通常是大字号核心槽点 / 亮点文字 + 夸张人物表情 / 精美素材）。
- 高对比度、避免杂乱。

**标题风格：**
- 可以稍微二次元化或夸张。
- 推荐模板：「硬核解析！」「全网最全！」「建议全屏观看！」「XX 万字长文整理！」。

## 社区语境与人设

**真诚是必杀技：**
- UP 主必须像跟朋友聊天一样交流，切忌端着或使用过于官方的新闻播音腔。
- 自称「在下」「小弟」或「老 X」类拟人化身份比「大家好我是 XX」更亲切。

**造梗能力：**
- 熟练运用平台现存的梗（「下次一定」「三连保护」「注入灵魂」「AWSL」）。
- 尝试创造属于自己账号的口头禅或视觉符号。

## 常见错误

| 错误做法 | 正确做法 |
|---|---|
| 1 分钟冗长片头 + 自报家门 | 30 秒内直接进入正题或抛出最震撼结论 |
| 整片单一机位、无变化 | 每 1-2 分钟切换场景或画面，避免视觉疲劳 |
| 通篇严肃新闻腔 | 像跟朋友聊天，可以自嘲、玩梗 |
| 不求三连、不引导互动 | 片尾真诚求三连（点赞 + 投币 + 收藏） |
| 标题平淡如水 | 使用二次元或夸张模板（「硬核解析！」「全网最全！」） |
| 封面纯文字 / 杂乱无章 | 高对比度视觉中心 + 大字号核心槽点 |
