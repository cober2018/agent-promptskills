# 加密货币链上指标分析

## 概述

加密货币（Crypto）等数字资产具有极高透明度，其区块链账本上的资产流动是关键的另类数据源。本技能包规范了交易所流入流出、大户（Whales）筹码移动、锁仓量（TVL）变化等链上指标的量化处理标准及 API 对接要求。

## 何时使用

*   量化策略研究员在跨资产大类配置中研判 Crypto 风险敞口与筹码结构。
*   捕获大宗异常转账或交易所资金快速流入以进行危机风控。
*   监测主流 DeFi 协议（如 Aave, Uniswap）的 TVL 变化以判定协议收益趋势。

**不要用于：**
*   传统的 A 股/港股等股票量化因子计算（使用 `quant-alpha-zoo`）。
*   纯粹的技术面指标均线交叉（使用 `technical` 或 `candlestick-pattern`）。

## 核心链上指标数学模型与判定

### 1. 交易所流入净流出 (Net Exchange Flow - NEF)
衡量二级市场潜在抛压的先行指标：

$$NEF_T = Inflow_T - Outflow_T$$

*   $Inflow_T$: $T$ 周期内转入交易所钱包的代币总量。
*   $Outflow_T$: $T$ 周期内转出交易所钱包的代币总量。
*   *触发条件*：当 $NEF_T > \text{mean}(NEF, 30) + 2 \times \sigma(NEF, 30)$ 且价格处于相对高位，判定为筹码转移抛压骤增，应触发一票否决或紧急防御。

### 2. 巨鲸筹码聚集度 (Whale Accumulation Score - WAS)
监测主力钱包地址的动态：
*   巨鲸钱包定义：持有代币总量占总流通量 $> 0.1\%$ 且非交易所/非协议合约的独立地址。
*   积攒得分 (WAS)：
    $$WAS_T = \frac{N_{buy} - N_{sell}}{N_{total\_whales}}$$
*   *有效判定*：$WAS > 0.2$ 代表巨鲸在增持吸筹，中线看涨；$WAS < -0.2$ 代表巨鲸在减持派发，中线看空。

### 3. TVL 异常变动 (TVL Anomaly Detection)
DeFi 生态的生命线指标：
*   当协议 $TVL_T$ 较前一日下滑 $> 15\%$，判定为资金快速流失，需立即核查该协议的智能合约是否存在安全漏洞或遭遇黑客闪电贷攻击。

## 交易所 CCXT 接口与另类数据调用规范

*   **CCXT 标准化**：在获取跨交易所（如 Binance、OKX）的挂单薄深度（Order Book Depth）、Funding Rate（资金费率）和交易数据时，必须通过 CCXT 封装层调用。
*   **异常回退**：对 Dune Analytics、Glassnode 等链上数据 API 的调用，如遭遇延迟或限制，必须设置默认的“历史静态数据”兜底，不得使整个 Swarm 系统挂起。

## 常见错误

| 错误做法 | 正确做法 |
|:---|:---|
| 将交易所热钱包内部划转误判为“外部巨鲸大额充值抛售” | 必须维护交易所已知钱包地址白名单，剔除交易所内部冷热钱包的对调交易 |
| 跨链 TVL 统计时重复计算重抵押代币（如 LST）造成的双重质押 | 采用去重算法，在计算净锁仓量时剔除桥接和衍生封装代币（如 wETH, stETH） |
| 未考虑 Gas Fee 剧烈波动对小额交易磨损的影响 | 在链上套利策略中，必须将实时 Gas 费（如以太坊 Gwei）作为交易磨损硬性扣减 |
