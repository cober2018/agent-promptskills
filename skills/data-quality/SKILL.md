# 数据质量

## 概述

数据可信吗？schema 变了吗？管线按时交付了吗？**数据质量不是事后补救，而是管线内建。**

## 何时使用

- 定义 DWS / ADS 表的数据契约
- 配置入口 / 出口 / 层间门禁
- 异常检测（统计异常 + Schema 漂移）
- 字段级血缘追踪
- 监控告警分级（P0 / P1 / P2）
- 每日数据质量报告生成

**不要用于：** 实时管线开发（用 `pipeline-engineering`）、数仓表结构设计（用 `lakehouse-platform`）、指标体系（用 `data-architecture`）。

## 数据契约（Data Contract）

**契约定义（每张 DWS / ADS 表必须有）：**

| 字段 | 说明 |
|---|---|
| 表名与描述 | 业务语义清晰 |
| Owner 团队 | 唯一责任方 |
| SLA（新鲜度承诺） | 如「交易日 T+60min 内可用」 |
| Schema 契约 | 字段名、类型、约束（NOT NULL / UNIQUE / 范围） |
| 上游依赖 | 依赖哪些 ODS / DWD 表 |
| 下游消费方 | 谁在用这张表、用于什么场景 |

**契约变更规则：**

| 变更 | 处理 |
|---|---|
| 加字段 | 非破坏性变更，通知消费方即可 |
| 改字段类型 / 删字段 | 破坏性变更，必须走迁移流程 |
| 改口径 | 即使技术上不破坏 schema，也必须通知消费方并记录 ADR |

## 五大质量维度

### 1. 完整性（Completeness）

必填字段不为空。**金融场景关键检查：**

| 检查 | 处置 |
|---|---|
| `adj_factor IS NULL` 数量 > 0 | 告警（复权因子缺失导致全链路错误） |
| `ts_code` 为空 | 立即阻断管线 |
| `trade_date` 为空 | 立即阻断管线 |

### 2. 准确性（Accuracy）

**数值范围校验：**

| 字段 | 规则 |
|---|---|
| 价格 | > 0（除 ST 股和退市股特殊处理） |
| 涨跌幅 `pct_chg` | -20% ~ +20%（主板）；-30% ~ +30%（创业板 / 科创板） |
| 成交量 `vol` | ≥ 0 |
| 复权因子 `adj_factor` | > 0 |

**交叉验证：**

- `close × vol` 应与 `amount` 数量级一致。
- 当日 `close` 与次日 `pre_close` 应一致（排除除权日）。

### 3. 一致性（Consistency）

- 同一标的同一交易日在不同层的数据应一致。
- ODS 行数与源系统行数对比偏差 < 0.1%。
- DWD 前复权价格与 ODS 原始价格 × adj_factor 误差 < 0.01。

### 4. 时效性（Timeliness）

| 表 | SLA 窗口 |
|---|---|
| ODS 日 K 数据 | 交易日 T+60min 内可用（16:00 采集，17:00 前就绪） |
| DWD 前复权表 | 交易日 T+120min 内可用（19:30 计算） |
| DWS 情绪因子 | 交易日 T+180min 内可用（20:00 聚合） |
| ODS 分钟 K 线（1min） | 实时推送延迟 p95 < 5s |
| ODS 行为埋点事件 | 端到端延迟 p95 < 30s（Kafka → ODS 可查） |
| DWS 用户行为日汇总 | T+1 09:00 前就绪（业务看板当日可见） |
| ADS AB 实验曝光 / 点击 / 转化漏斗 | T+1 08:00 前就绪 |
| ADS LTV（30 / 90 / 365） | T+1 12:00 前就绪 |

### 5. 唯一性（Uniqueness）

- `ReplacingMergeTree` 保证最终唯一（合并后按主键 + version 去重）。
- 查询时加 `FINAL` 关键字获取去重后结果。
- 定期检查：`SELECT count()` vs `SELECT count() ... FINAL` 差异应趋近 0。

## 质量门禁（Quality Gate）

### 管线入口门禁（写入前检查）

| 检查 | 处置 |
|---|---|
| Schema 校验：字段名、类型 | 与目标表一致 |
| 行数校验 | 当日行数 vs 历史均值，波动 > 30% → 告警 |
| 空值检查 | 核心字段空值率超过阈值 → 阻断 |
| 重复检查 | 主键重复率 > 0% → 告警（ReplacingMergeTree 会处理，但需要知道） |

### 管线出口门禁（写入后检查）

- 行数验证：写入行数与源数据行数一致。
- 时间戳验证：最新记录的 `trade_date` 是否为当天。
- 抽样校验：随机抽取 N 条记录，对比源数据。

### 层间传递门禁

| 上 → 下 | 触发条件 |
|---|---|
| ODS → DWD | ODS 数据就绪且通过入口门禁后，DWD 管线才启动 |
| DWD → DWS | DWD 前复权表行数 > 0 且 adj_factor 无空值 |
| DWS → ADS | DWS 聚合表的 trade_date 包含当天 |

## 异常检测

### 统计异常

- 行数异常：当日行数偏离最近 30 天均值超过 2 个标准差。
- 空值率异常：某字段空值率突然升高。
- 数值异常：价格出现负值、成交量出现极端值。

### Schema 漂移

| 漂移 | 处置 |
|---|---|
| 源系统返回了新字段 | 记录并告警 |
| 源系统删除了字段 | 立即告警并暂停管线 |
| 字段类型变更 | 立即告警并暂停管线 |

### 时效性异常

- 管线执行超时（超过历史平均的 3 倍）。
- 数据未在 SLA 窗口内到达目标表。
- 上游数据源 API 无响应或返回空数据。

## 用户权限与敏感数据审计

### 权限模型（RBAC + ABAC）

| 维度 | 规则 |
|---|---|
| 角色 | 数据工程师 / 分析师 / 业务方 / 外部合作方 |
| 资源粒度 | 表级 / 字段级 / 行级（按租户 / 业务线过滤） |
| 操作粒度 | 读 / 写 / 导出 / 删除 / 变更 Schema |
| 鉴权位置 | 数据访问层统一拦截（不要在每个查询处判断） |

**最小权限原则：**

- 默认拒绝，按需授予；权限变更走审批流。
- 高敏字段（身份证、银行卡、API Token、用户手机号）单独管控，仅白名单角色可读且必须经脱敏。
- 外部数据共享必须经过数据脱敏 + 导出审批，文件带水印与有效期。

### 敏感字段保护

| 字段类型 | 处置 |
|---|---|
| 身份证号 | 入 ODS 即 Hash（SHA-256 + salt），出仓仅展示后四位 |
| 手机号 / 邮箱 | 入 ODS 即脱敏（138****8000） |
| API Token / 私钥 | 严禁进入 ODS；走独立密钥管理服务（KMS） |
| 金融账户 | 仅展示脱敏卡号；导出时强制审批 |

### 审计日志（必留痕）

| 审计项 | 内容 |
|---|---|
| 访问审计 | 谁、什么时间、用什么账号、读了哪张表 / 哪些字段、几行 |
| 变更审计 | DDL / DML 变更、执行人、变更前快照、变更理由 |
| 导出审计 | 导出文件路径、记录数、脱敏方式、审批单号、有效期 |
| 异常审计 | 短时间内大批量查询、非工作时间访问、跨租户访问 |

审计日志写入独立存储（不进 ODS），保留 ≥ 180 天，关键操作保留 ≥ 3 年。

## AB 实验数据质量

### SRM（Sample Ratio Mismatch）监控

**定义：** 实验实际分流比例与配置预期比例显著偏离（卡方检验 p < 0.01），通常意味着分流器 bug、用户去重逻辑错误或数据采集缺失。

| 指标 | 规则 |
|---|---|
| 监控时机 | 实验启动后 1h / 24h / 72h |
| 检验方法 | 卡方检验（χ² test），p < 0.01 触发 P0 告警 |
| 处置 | 暂停该实验数据消费 → 排查分流器 → 必要时回滚实验 |

### 实验数据完整性

- 实验分桶字段（`exp_id`、`bucket`）强制非空。
- 实验周期内用户不应跨桶漂移（同 `user_id` + `exp_id` 在不同时间应映射到同一桶）。
- 核心事件（曝光 / 点击 / 转化）埋点率 ≥ 95% 视为合格；< 90% 触发 P1 告警。

## 数据血缘

### 表级血缘（必须维护）

- 每张 DWD / DWS / ADS 表都标注数据来源表。
- 变更上游表结构前，先查血缘确认下游影响。

### 字段级血缘（核心字段维护）

- 前复权价格字段追溯到 ODS 原始价格 + adj_factor。
- 情绪因子追溯到涨停板、封板率等原始指标。
- 策略信号追溯到因子值 + 策略参数。
- 用户转化漏斗字段追溯到埋点事件 ID。
- LTV 字段追溯到订单流水 + 用户分群。

**项目血缘图示例：**

```
Tushare API → ods_astock_daily_his_df
                  ↓
             dwd_astock_daily_adj_df（前复权）
                  ↓
             dws_astock_sentiment_factors_daily_df（情绪因子）
                  ↓
             ads_factor_value_df（因子值）
```

## 监控与告警

### 监控指标

| 指标 | 告警阈值 |
|---|---|
| 采集数据量 | 当日行数 vs 历史均值，波动 > 30% |
| 复权因子缺失 | `adj_factor IS NULL` 数量 > 0 |
| 行情连续性 | 股票在某交易日无数据 > 5% |
| 视图数据完整性 | 15 / 30 分钟视图行数波动 > 10% |
| 管线执行时间 | 超过 SLA 窗口 |
| 行为埋点到达率 | 核心事件埋点率 < 95% |
| 缓存与底层一致性 | 抽样比对差异 > 1% |
| 权限异常访问 | 非工作时间大批量读 / 跨租户读 / 高敏字段直读 |
| AB 实验 SRM | 卡方检验 p < 0.01 触发 P0 告警 |

### 告警分级

| 等级 | 触发条件 | 响应时间 | 渠道 |
|---|---|---|---|
| **P0** | 管线中断 / 数据损坏 | 5 分钟内 | 钉钉 / 飞书实时告警 |
| **P1** | 质量退化 / SLA 超时 | 30 分钟内 | 钉钉 / 飞书 |
| **P2** | 统计异常 / Schema 漂移 | 当日 | 每日质量报告汇总 |

## 常见错误

| 错误做法 | 正确做法 |
|---|---|
| 出现空值才告警 | 入口门禁阻断，空值率超阈值即停 |
| 检测到漂移后继续运行 | 立即暂停管线，告警，等人工确认 |
| 行数波动不监控 | 行数偏离 30% 即告警 |
| 血缘只到表级 | 核心字段也要做字段级血缘 |
| 所有告警都 P0 | 按 P0 / P1 / P2 分级，避免告警疲劳 |
